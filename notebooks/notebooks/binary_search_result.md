### 1. Объяснение алгоритма
Бинарный поиск находит целевое значение в **отсортированном** массиве, многократно деля поисковый интервал пополам.  
На каждом шаге алгоритм сравнивает цель со средним элементом:
- если равны — возвращает индекс;
- если цель больше — отбрасывает левую половину;
- если цель меньше — отбрасывает правую половину.

**Сложность:**  
- Время: **O(log n)**  
- Память: **O(1)** (итеративная реализация)

---

### 2. Реализация на Python
```python
def binary_search(arr, target):
    """Return the index of target in sorted list arr, or -1 if not found."""
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**Особенности:**
- Корректная инициализация границ (`left=0`, `right=len(arr)-1`).
- Вычисление середины через целочисленное деление.
- Возврат индекса при нахождении, иначе `-1`.
- Работает за O(1) дополнительной памяти.

### 3. Тесты на граничных случаях (pytest)
```python
import pytest
from binary_search import binary_search

def test_empty_list():
    assert binary_search([], 5) == -1

def test_single_element_found():
    assert binary_search([42], 42) == 0

def test_single_element_not_found():
    assert binary_search([42], 99) == -1

def test_target_not_present():
    assert binary_search([1, 3, 5, 7, 9], 6) == -1

def test_duplicates():
    arr = [1, 2, 2, 2, 3]
    idx = binary_search(arr, 2)
    assert idx != -1 and arr[idx] == 2

def test_large_list_present():
    large = list(range(1_000_000))
    assert binary_search(large, 500_000) == 500_000

def test_large_list_absent():
    large = list(range(1_000_000))
    assert binary_search(large, 1_500_000) == -1
```

**Покрытые случаи:**
- Пустой список
- Один элемент (найден / не найден)
- Цель отсутствует в массиве
- Дубликаты (возвращается любой корректный индекс)
- Большой массив (1 млн элементов) — цель присутствует / отсутствует
